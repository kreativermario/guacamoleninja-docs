# guacamoleninja-docs

Docusaurus documentation site for GuacamoleNinja, deployed to Cloudflare Pages.

## Commands

```bash
pnpm run start    # dev server
pnpm run build    # production build
pnpm run serve    # serve built output locally
```

## Stack

- Docusaurus 3.x
- React 19
- Deployed via Cloudflare Pages (`guacamoleninja-docs` project)
