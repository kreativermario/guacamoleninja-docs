# Requirements

Before running guacamoleninja-bot you need:

- **Node.js 24** (LTS)
- **pnpm 11+** — `npm install -g pnpm`
- **Docker + Docker Compose** — for the local PostgreSQL database
- A **Discord application** with a bot token and client ID ([create one](https://discord.com/developers/applications))
